1. Architecture Overview

┌─────────────────────────────────────────────────────────────────┐ │ xmlBluePrint │ │ ┌─────────────────────────────────────────────────────────┐ │ │ │ • State Machine (54 states) │ │ │ │ • TOC[54][256] — Transition Table (CELL handlers) │ │ │ │ • Path Tree (xmlBluePrintNode) — hash-based routing │ │ │ │ • Log Store — ring buffer of structural fingerprints │ │ │ │ • Similarity Scorer — tag sequence + distance ratios │ │ │ │ • Thread Lifecycle (run/pause/resume/shutdown) │ │ │ └─────────────────────────────────────────────────────────┘ │ └─────────────────────────────────────────────────────────────────┘ │ ┌───────────────┼───────────────┐ ▼ ▼ ▼ ┌──────────┐ ┌──────────┐ ┌──────────┐ │ Holder 0 │ │ Holder 1 │ │ Holder N │ │ (Thread) │ │ (Thread) │ │ (Thread) │ ├──────────┤ ├──────────┤ ├──────────┤ │ Job Ring │ │ Job Ring │ │ Job Ring │ │ (512) │ │ (512) │ │ (512) │ │ Log Buf │ │ Log Buf │ │ Log Buf │ │ Pred. │ │ Pred. │ │ Pred. │ └──────────┘ └──────────┘ └──────────┘ ▲ ▲ ▲ └───────────────┼───────────────┘ ▼ ┌─────────────────┐ │ Distributor │ │ Thread │ │ (Round-robin) │ └─────────────────┘ ▲ │ pushJob() ┌─────────┴─────────┐ │ Producer │ │ (User Code) │ └───────────────────┘

Core Design Principles

  • Separation of concerns: Blueprint = read-only shared logic; Holder = per-thread mutable state
  • Zero-allocation hot path: No object creation during byte parsing
  • Lock-free concurrency: Ring buffers + VarHandle.fullFence() + LockSupport.park/unpark
  • Table-driven dispatch: TOC[state][byte] → O(1) array load + virtual call

2. Finite State Machine (FSM)

State Constants (54 states)

RangeStatesPurpose
0-3S_HEADER, S_HEAD_LT, S_HEADER_BANG, S_HEADER_PIPrologue detection
4-14S_HEADER_DASH...S_HEADER_CComment/PI/XML decl parsing
15-31S_EN...S_CHR_CHARSETencoding= / charset= attribute parsing
32-34S_HEAD_CHAR, S_ROOT_OPEN, S_NEXT_XMLRoot tag detection & open
35-40S_TARGET_INNER, S_TARGET_ATTR, S_VAL_ATTR, S_QUOTE_VALUE, S_DQUOTE_VALUE, S_VAL_VALUETarget track (registered paths)
41-53S_LT, S_BANG...S_UNREGIST_BRANCHShared & non-target track

State Categories

  • Prologue states (0-31): Outside root — detect XML decl, comments, PI
  • Root states (32-34): Find and validate root element
  • Target states (35-40): Active callback collection for registered paths
  • Non-target states (41-53): Structural parsing without callbacks
State number is the "am I collecting data?" flag — target states (35-40) have callbacks; others don't. This is the key optimization.

3. Transition Table (TOC)

Structure

CELL[][] TOC = new CELL[54][256];  // [state][byte] → handler

Construction Layers (in constructor)

  1. Default: All [state][byte] = HD_SAMESTATE (pointer++)
  2. UTF-8 Fast Path (all states):
    • 0xC0-0xDF → SKIP2_HANDLER (2-byte sequence)
    • 0xE0-0xEF → SKIP3_HANDLER (3-byte sequence)
    • 0xF0-0xF7 → SKIP4_HANDLER (4-byte sequence)
  3. Per-state defaults: for(j=255..0) TOC[S_X][j] = HD_FALLBACK
  4. Specific transitions: Explicit byte→handler mappings

Key Handlers

HandlerPurpose
HD_SAMESTATEDefault: pointer++ (stay in state)
SKIP2/3/4_HANDLERSkip UTF-8 multi-byte sequences
HD_OPENTAGProcess opening tag, hash lookup, dispatch
HD_ENDTAG_NAMEProcess closing tag, skip depth management
HD_ROOT_OPENRoot element open, init log/prediction
HD_CLOSINGTAG / HD_CLOSINGROOTTag close, parent ascent, callbacks

Adding New Transitions

// In xmlBluePrint constructor:
TOC[MY_STATE]['x'] = MY_HANDLER;
TOC[MY_STATE]['>'] = MY_HANDLER;
// Default for all other bytes:
for (int j = 255; j >= 0; j--) TOC[MY_STATE][j] = HD_FALLBACK;

4. Path Tree & Hash Matching

Tree Structure (xmlBluePrintNode)

class xmlBluePrintNode {
    long tagHash;                    // FNV-1a + SplitMix64
    xmlBluePrintCall handler;        // null for routing nodes
    Object idToken;                  // user token
    Map children;  // hash → child
    xmlBluePrintNode parent;         // for close tag ascent
    boolean isTarget;                // last segment of regist()
    boolean isChildOfTarget;         // parent was target
    CELL HD_CLOSINGTAG;              // per-node close handler
}

Registration Example

regist("/catalog/book/author", handler, "author");

// Creates:
root (hash=0)
  └─ "catalog" (hash=H1, isTarget=false)
       └─ "book" (hash=H2, isTarget=false)
            └─ "author" (hash=H3, isTarget=true, handler, token)

Hash Function

static long hash(byte[] buf, int begin, int end) {
    long h = 0xCBF29CE484222325L;  // FNV offset basis
    for (int i = begin; i < end; i++) {
        byte v = buf[i];
        if (v == ':' || v == '}') break;  // Strip namespace
        h ^= (v & 0xFF);
        h *= 0x100000001B3L;              // FNV prime
    }
    // SplitMix64 finalizer
    h ^= h >>> 33;
    h *= 0xFF51AFD7ED558CCDL;
    h ^= h >>> 33;
    h *= 0xC4CEB9FE1A85EC53L;
    h ^= h >>> 33;
    return h;
}
Namespace stripping: Hash stops at : or }, so ns:Book, {uri}Book, and Book all hash identically.

Matching Logic (in HD_OPENTAG)

long hTagName = hash(buf, tagName, tagNameEnd);

if (holder.skipDepth > 0) {           // In skip mode
    if (hTagName == holder.skipName && !isSelfClosed)
        holder.skipDepth++;
    state = S_UNREGIST_BRANCH;
} else if (!currentNode.hasChild(hTagName)) {  // Unregistered
    holder.skipName = hTagName;
    holder.skipDepth = 1;
    state = S_UNREGIST_BRANCH;
} else {                              // Registered
    holder.currentNode = holder.currentNode.getChild(hTagName);
    if (holder.currentNode.isTarget) fireOpenTag();
    // ... handle attrs, self-close, etc.
}
Unregistered Branch Handling (No Depth Limit): The parser tracks the first unregistered tag name (by hash) and a depth counter. On same tag name: depth++ (open) or depth-- (close). When depth returns to 0: exits skip mode. No XML syntax validation in skipped branches — malformed content is silently ignored.

5. State Handlers (CELL)

Interface

interface CELL {
    void call(xmlBluePrintHolder holder);
}

Handler Responsibilities

  1. Read bytes from holder.jobStart[holder.cp] at holder.pointer
  2. Advance holder.pointer
  3. Update holder.xmlState (next state)
  4. Update routing context (currentNode, skipDepth, offsets)
  5. Call user callback (xmlBluePrintCall) for events

Common Patterns

Simple State Advance

private static final CELL HD_SIMPLE = new CELL() {
    public void call(xmlBluePrintHolder holder) {
        holder.pointer++;
        holder.xmlState = NEXT_STATE;
    }
};

Skip N Bytes

private static final CELL SKIP2_HANDLER = new CELL() {
    public void call(xmlBluePrintHolder holder) {
        holder.pointer += 2;  // UTF-8 2-byte sequence
    }
};

Collect Offsets & Callback

private static final CELL HD_ATTR = new CELL() {
    public void call(xmlBluePrintHolder holder) {
        holder.attrEnd = holder.pointer++;
        if (holder.attrEnd > holder.attrName) {
            if (!holder.currentNode.handler.call(
                holder.currentNode.idToken, holder,
                EV_ATTR, holder.attrName, holder.attrEnd,
                holder.value, holder.valEnd)) {
                HD_NEXT_XML(holder);  // Abort document
            }
        }
    }
};

Handler Registration

Handlers are static final singletons defined in xmlBluePrint and wired in the constructor:

TOC[S_TARGET_ATTR]['='] = HD_VAL_ATTR;
TOC[S_TARGET_ATTR][' '] = HD_NOVAL_ATTR;
TOC[S_TARGET_ATTR]['>'] = HD_NOVAL_ATTR;

6. Threading Model & Job Queues

Holder-Centric Job Distribution

XMLFastReader does not use a central global queue. Instead, pushJob() distributes XML jobs directly to holder queues in a round‑robin manner. Each worker thread owns its holder and processes jobs from its own ring buffer.

Holder Queue (Ring Buffer)

// Size: 2^N (configured via setQueSize(N); minimum N=2 => size=4)
volatile byte[][] jobStart;
volatile Object[] tokenFile;
volatile int[] jobLength;
volatile int cp = 0, pp = 0;

// Space available in holder queue:
(cp - pp - 1) & (jobQueSize - 1)

Flow

Producer                    Workers (Holder)
  │                           │
  ├─ pushJob() ──────────────►│
  │    (writes to holder[pp]) │
  │                           │
  │                           ├─ holder.nextJob() ───────►│
  │                           │    (advances holder cp)   │
  │                           │                           │
  │                           │                    holder.nextJob()
  │                           │                    (advances holder cp)
  │                           │                           │
  │                           │                    while(pointer < len)
  │                           │                       TOC[state][byte].call()

Synchronization

  • Memory barriers: VarHandle.fullFence() after slot writes, before pointer publish
  • Park/Unpark: LockSupport.parkNanos() / unpark() — no locks
  • Volatile pointers: cp/pp for visibility

Lifecycle Flags

volatile boolean running = false;
volatile boolean paused = false;
volatile boolean shuttingdown = false;
volatile boolean forceShutdown = false;

8. Extending the Parser

Adding New Events

  1. Add constant to xmlBluePrint: EV_MY_EVENT = 5
  2. Fire in appropriate handler: handler.call(token, holder, EV_MY_EVENT, ...)
  3. Update xmlBluePrintCall documentation

Adding New States

  1. Add constant: S_MY_STATE = 54, increment xmlState_MAX
  2. Initialize TOC row in constructor
  3. Add handler CELL implementation
  4. Wire transitions from other states

Custom Charset/Encoding

Parser detects encoding and charset in XML decl. Stored in holder.charset (defaults to UTF-8). FSM assumes ASCII-compatible/UTF-8.

Subclassing xmlBluePrint

class MyParser extends xmlBluePrint {
    @Override
    protected void collectLog(LogEntry log, byte[] name, int nameLen) {
        // Custom log persistence (DB, file, metrics)
        super.collectLog(log);  // Keep default behavior
    }
}

Custom Skip Logic

Modify HD_OPENTAG and HD_ENDTAG_NAME skip depth handling for different unregistered branch strategies.

9. Performance Tuning

Thread Count

ScenarioRecommended Threads
Small files, CPU-boundCPU cores
Large files, I/O wait2-4 × CPU cores
Latency-sensitive1 (no context switching)

Queue Sizes

  • Global: 16K (fixed) — increase if bursty producer
  • Holder: 512 (fixed) — increase for large documents

Hot Path Optimizations

  • Zero allocation: Callbacks use offsets — no new String() in FSM
  • UTF-8 skip: Multi-byte sequences bypass state machine
  • Hash boxing: HashMap boxes on each open tag — consider long[] parallel arrays for extreme throughput
  • VarHandle fence: Only on producer side; workers read volatile

Predictive Gains

  • Works best for: same tag order, variable spacing/attributes
  • No gain for: structurally different documents
  • Fallback cost: one tag hash verification per prediction

Profiling Tips

-XX:+PrintCompilation -XX:+UnlockDiagnosticVMOptions
-XX:+PrintInlining -XX:CompileCommand=print,xmlBluePrint.xmlBluePrintHolder::nextJob

Logging

// Add to handlers for trace:
System.err.printf("STATE=%d PTR=%d BYTE=%c%n",
    holder.xmlState, holder.pointer,
    (char)holder.jobStart[holder.cp][holder.pointer]);

Common Issues

  • EV_END_NE_BEGIN: Closing tag hash ≠ opening — check root.tagHash set in HD_ROOT_OPEN
  • Stuck in S_UNREGIST_BRANCH: Skip depth not decrementing — check HD_ENDTAG_NAME
  • No callbacks: Path not registered, or isTarget=false
  • Queue full: Increase threads or add backpressure
  • Prediction never activates: Need at least 2 targets in historical log

Inspecting Logs

// After parsing:
xmlBluePrint.LogEntry[] logs = xmlBluePrint.getCollectedLogs();
for (LogEntry log : logs) {
    for (int i = 0; i < log.size; i++) {
        System.out.printf("dist=%d hash=%016x%n",
            log.distances[i], log.hashes[i]);
    }
}
