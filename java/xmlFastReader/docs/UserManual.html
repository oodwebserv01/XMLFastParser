xmlFastReader User Manual

Easy-to-use API powered by the core algorithm xmlFastParser — with examples from testXmlFastReader.java

01 Project Overview

xmlFastReader is a simple-to-use API that reads XML documents and extracts data into tables (entity/column) according to a format defined in a .bp (blueprint) file. It relies on xmlFastParser as the core engine for parsing XML in a multi-threaded pipeline.

Key files in the sub-project:

File

Role

XmlFastReader.java

Main API — create instance, set blueprint, parse, shutdown

BPParser.java

Reads .bp file and creates TokenEntity / TokenColumn

EventHandlers.java

4 handlers: HD_Root, HD_Error, HD_Entity, HD_Column

XmlToken.java

Pipeline token — carries XmlPackage, result buffer buffOP, error message msgError

XmlPackage.java

Wraps XML data (byte[], size, idFile, name)

02 Blueprint File Format (.bp)

Before using the API, prepare a .bp file to tell the parser: “For any XML document with this entity name, extract data from this XPath as columns.”

file:Invoids            # Entity / output file name
entity:/Transaction     # XPath of the main document
- /Transaction/Invoid@SN  # Attribute column @SN
- /Transaction/Invoid#    # Inner text column

  • file: Entity name (used as key in output)

  • entity: XPath of the tag considered one row

  • - /path#: Inner text (content between open/close tags)

  • - /path@attr: Attribute of the tag

Note: BPParser.parseBP() creates TokenEntity and TokenColumn from this file, then passes them to XmlFastReader.setBP() to register with the parser.

03 Usage Steps (from testXmlFastReader.java)

The example from test/testXmlFastReader.java demonstrates the full workflow in 6 steps:

1 Create Instance

XmlFastReader reader = new XmlFastReader();

Creates the main API object, which will instantiate xmlBluePrint when setBP() is called.

2 Set Blueprint (setBP)

reader.setBP("/home/wise0136/NetBeansProjects/Lab/BluePrint.bp");

Inside setBP():

  1. Creates xmlBluePrint (pipeline depth = 2, threads = 1)

  2. Calls BPParser.parseBP() to read .bp

  3. Creates TokenRoot (bound to main thread + entity map)

  4. Registers EventHandlers.HD_Root and HD_Error

  5. Registers HD_Entity per entity path and HD_Column per column path

  6. Calls parser.run() to start the parser

Important: Always call setBP() before parse(); otherwise it throws IllegalStateException.

3 Read XML as byte[]

String file = "/home/wise0136/NetBeansProjects/Lab/Case_1/TP099400018234140061000002564.xml";
byte[] job = Files.readAllBytes(Paths.get(file));

Reads the XML document fully into memory as a byte[] to pass into the parser.

4 Parse (parse())

HashMap<String, String[][]> ret = reader.parse(job, file);

Inside parse():

  1. Creates new XmlToken

  2. Sets XmlPackage (byteBuffer = job, size = job.length, name = file)

  3. Pushes job to parser with parser.pushJob()

  4. Waits for result from parser.pullJob() (parks 200,000 ns per loop) until XmlToken is returned

  5. Splits buffOP (key = entity name, value = concatenated rows) into String[][]

Data format inside buffOP before splitting:

entityName~row1~row2~...

Rows are separated by ~, and columns within each row are separated by ` (backtick).

5 Process Results

ret.forEach((key,val)->{
    // key = entity name (e.g., "Invoids")
    // val = String[][] — rows × columns
    // val[0][0] = fileName, val[0][1] = first column, ...
    writeEntity(key,val,"/path/to/output");
});

Sample write function from testXmlFastReader.java:

static void writeEntity(String file, String[][] rows, String path) throws Exception {
    String out = path+"/"+file+".txt";
    if (rows == null) return;
    String allRow = "";
    for (int r = 0; r < rows.length; r++) {
        String row = "";
        for (int c = 0; c < rows[r].length; c++) {
            row += ",\""+rows[r][c] +"\"";
        }
        allRow += row.substring(1)+"\n";
    }
    Files.write(Paths.get(out), allRow.getBytes(StandardCharsets.UTF_8));
}

The output is a simple CSV: the first column is the file name (from XmlPackage.name), followed by other columns in the order defined in .bp.

6 Shutdown (shutdown)

reader.shutdown();

Inside shutdown(), it calls parser.shutdown(true) to stop the pipeline and release resources.

Usage note: You can call setBP() once, then call parse() multiple times — as many times as needed — until you finally call shutdown() to release the parser pipeline.

05 Core Algorithm Overview (xmlFastParser)

Although xmlFastReader is a simple API, the underlying xmlFastParser works as an event-driven pipeline:

  • EV_OPEN_TAG / EV_CLOSE_TAG: Triggers row assembly via HD_Entity and HD_Root

  • EV_INNER_TEXT: Stores text between tags into columns via HD_Column

  • EV_ATTR: Stores attribute values based on attribute name hash

  • EV_ERROR / EV_RESET_IN_SAFEMODE: HD_Error handles errors and only allows continuation for safe-mode reset events

Therefore, users do not need to worry about parsing themselves — just define .bp, then pass byte[] through XmlFastReader.parse().

06 Full Example Code (from testXmlFastReader.java)

package xmlFastReader;
import java.nio.file.*;
import java.util.*;

public class testXmlFastReader {
    public static void main(String[] args) throws Exception {
        XmlFastReader reader = new XmlFastReader();
        reader.setBP("/home/wise0136/NetBeansProjects/Lab/BluePrint.bp");
        String file = "/home/wise0136/NetBeansProjects/Lab/Case_1/TP099400018234140061000002564.xml";
        byte[] job = Files.readAllBytes(Paths.get(file));
        HashMap<String, String[][]> ret = reader.parse(job, file);
        ret.forEach((key,val)->{
            try {
                writeEntity(key,val,"/home/wise0136/NetBeansProjects/xmlFastReader/xmlFastReader/target");
            } catch(Exception e){
                System.out.println(e.getMessage());
                e.printStackTrace();
            }
        });
        System.out.println("testXmlFastReader finished — ret keys: " + ret.keySet());
        reader.shutdown();
    }

    static void writeEntity(String file, String[][] rows, String path) throws Exception {
        String out = path+"/"+file+".txt";
        if (rows == null) return;
        String allRow = "";
        for (int r = 0; r < rows.length; r++) {
            String row = "";
            for (int c = 0; c < rows[r].length; c++) {
                row += ",\""+rows[r][c] +"\"";
            }
            allRow += row.substring(1)+"\n";
        }
        Files.write(Paths.get(out), allRow.getBytes(java.nio.charset.StandardCharsets.UTF_8));
        System.out.println("Wrote " + out + " (" + rows.length + " rows)");
    }
}

07 Warnings and Recommendations

  • Call setBP() before parse() — otherwise throws IllegalStateException

  • .bp must include both file: and entity: — BPParser will not create entities without a path

  • Results in buffOP may be empty if XML does not match XPath in .bp

  • Use shutdown() after finishing to release parser pipeline resources

  • Output is String[][], not objects, so it is easy to write as CSV / TXT
