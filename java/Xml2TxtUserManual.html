XML2TXT User Manual

Usage: java -cp compiled XML2TXT -p <bp> -s <src> -d <dest> [-t threads] [-N 7] [-b 1]

  • -p blueprint (.bp)
  • -s source folder
  • -d destination folder
  • -t parser threads (default 1)
  • -N pipeline depth 2-16 (default 7, sweet spot 1M XML)
  • -b flush batch 1-10000 (default 1; benchmark used 1)

Output naming: [entityName]_ThreadNo_YYYYMMDDHHmmss.txt. Pending file written first, renamed on ClosingJob.

Blueprint (.bp) Structure

file:Invoids → output file name · entity:/rsm:SupplyChainTradeTransaction → root node · lines - /path# = text value · - /path@schemeID = attribute.
Example .bp (from GOAL.md):

file:Invoids
entity:/Transaction
- /Transaction/Invoid@SN
- /Transaction/Invoid/Saler/PersonID#
- /Transaction/Invoid/Buyer/PersonID#
- /Transaction/Invoid/Items@Count
- /Transaction/Invoid/Summary#

file:Items
entity:/Transaction/Invoid/Items/Item
- /Transaction/Invoid/Items/Item@ID
- /Transaction/Invoid/Items/Item/Name#
- /Transaction/Invoid/Items/Item/Quantity#
- /Transaction/Invoid/Items/Item/UnitPrice#
- /Transaction/Invoid/Items/Item/TotalPrice#

Default entity: If entity: is not specified, default is <root> (root XML element).

Phases

Pipeline slots = 2^N-1 (N=2→3, 3→7, 4→15, 5→31, 6→63, 7→127, 8→255). Sweet spot ≈ N7 (127 slots, default) for -t1 / 1M XML; N8 risk RAM/swap

  1. BootUp: parse BP, register handlers, prepare writers
  2. MainLoop: fill pipeline, process XML/zip, flush to output
  3. ClosingJob: close writers, rename pending files, shutdown parser
