XML2TXT Developer Deeper Manual

Parser Tuning

Slot count formula: (2^N)-1. N=2 => 3 slots; N=4 => 15; N=5 => 31.

Set C_PipeLineDeep via -N (2–16, default 2). Higher depth increases pipeline slots but increases memory for tokens and buffer reuse.

Flush Behavior

flushXmlToken writes each entry via PrintWriter.println(); disk flush occurs every 1000 records (flushBatchCount % 1000 == 0). This is the main disk-I/O bottleneck.

Threading

Parser uses setThreadCount(-t); MainLoop runs in single thread pulling from parser. Multi-thread improves parser throughput but flush remains single-threaded.

File Sources

SourceHandler.getXml() returns XmlPackage objects; supports .xml directly and .zip entries containing .xml.

Blueprint Parsing

BPParser.parseBP() produces HashMap<Long, TokenEntity>; entities and columns registered via parser.regist(path, handler, obj).
